COMPLETE WORKFLOW:

1️⃣  UPLOAD ID
    │
    ├─ User uploads government-issued ID photo
    │
    ├─ IDFaceExtractor processes image
    │   • Detects face in document
    │   • Crops face region
    │   • Saves to Extracted_Faces/face_TIMESTAMP.jpg
    │
    └─ Frontend receives face URL
        Status: ✅ Ready for liveness check

2️⃣  LIVENESS DETECTION
    │
    ├─ User activates webcam
    │
    ├─ Continuous frame capture (1 fps)
    │
    ├─ Each frame sent to AntiSpoofingEngine
    │   • MiniFASNet V1SE model check
    │   • MiniFASNet V2 model check
    │   • Aggregate scores
    │   • Determine if real or spoof
    │
    └─ Loop until: is_live = true
        Status: ✅ Liveness confirmed

3️⃣  FACE VERIFICATION ★ ISF.py INTEGRATION ★
    │
    ├─ Live capture + ID face sent to /verify-identity
    │
    ├─ FaceVerificationSystem.verify() called
    │   │
    │   ├─ Load ID face: extract_face_embedding(id_photo_path)
    │   │   • Assess image quality
    │   │   • Apply preprocessing (if needed)
    │   │   • Extract 512-D ArcFace embedding
    │   │
    │   ├─ Load live face: extract_face_embedding(live_photo_path)
    │   │   • No preprocessing (preserve authenticity)
    │   │   • Extract 512-D ArcFace embedding
    │   │
    │   ├─ Calculate similarity: cosine_similarity(emb1, emb2)
    │   │
    │   ├─ Adaptive thresholding based on ID quality:
    │   │   • Quality < 40: threshold = 0.40 (lenient)
    │   │   • Quality < 60: threshold = 0.60 (moderate)
    │   │   • Quality ≥ 60: threshold = 0.70 (standard)
    │   │
    │   └─ Determine match: similarity > threshold
    │
    └─ Return comprehensive result
        Status: ✅ Verification complete
